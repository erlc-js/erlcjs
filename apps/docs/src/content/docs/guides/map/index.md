`@erlcjs/map` draws a PNG map from a server's player and emergency-call caches. It supports ER:LC's built-in maps, custom backgrounds, Roblox headshots, team-colored pins, and mod-call badges.

[Read the map guide](/docs/guides/map/getting-started/)
